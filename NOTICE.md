# Notice

This project is a C++ port of the digital filtering functions from SciPy, a Python library for scientific computing. The implementation closely follows SciPy's code structure and algorithms, with adaptations to C++ programming paradigms.

## Acknowledgments

We acknowledge the SciPy developers and contributors for their excellent work on the original implementation. This C++ port aims to provide the same functionality while leveraging the performance advantages of C++.
